# OpenCode Instructions

Use [`AGENTS.md`](./AGENTS.md) as the operating guide for this repo.

Use OpenCode's native Plan agent, Build agent, subagents, permissions, commands, and `skill` tool before adding custom workflow files. The adapters in `.agents/skills/` expose the canonical skills to OpenCode's native skill discovery.

When a task maps to a recurring workflow, load the corresponding `SKILL.md` and follow it as process guidance around OpenCode's native tools. Keep work small, verified, and easy to hand off.
